# Grafo Bipartido

Um grafo onde existe 2 "partes" do grafo e cada vértice de uma parte possui conexão a outro vértice da outra parte.

Se cada vértice de uma parte se conecta a todos os vértices da outra, veja [[Grafo Bipartido Completo]].
