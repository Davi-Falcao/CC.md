## O que são padrões de projeto?

Padrões de projeto são soluções recorrentes para problemas comuns no desenho de software. Eles descrevem uma forma de organizar responsabilidades e relações entre objetos, não um código pronto para copiar. Servem também como vocabulário compartilhado para discutir escolhas de design. Use um padrão quando ele resolver um problema real: a simplicidade da solução importa mais do que aplicar um padrão por obrigação.

Os padrões podem ser agrupados pelo tipo de problema que ajudam a resolver.
